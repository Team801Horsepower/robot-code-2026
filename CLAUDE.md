# Repository Rules

## ABOUT File Archiving

Project specification documents use the naming convention `ABOUTx.md` (e.g., `ABOUT1.md`, `ABOUT2.md`).

**Rule:** Any time an `ABOUTx.md` file is originally created or used in this repository, copy it to `C:\Users\hudso\clean-clones\new-repo\ABOUT-ARCHIVE\` with a letter suffix appended:
- First version: `ABOUT1a.md`
- Second version of the same file: `ABOUT1b.md`
- Third version: `ABOUT1c.md`
- And so on, incrementing the letter for each subsequent version of the same numbered ABOUT file.

The archive directory is: `C:\Users\hudso\clean-clones\new-repo\ABOUT-ARCHIVE\`
