# Test Mode Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a hardware checkout mode using WPILib's Test mode that runs all non-drivetrain motors at 0.1 power via dedicated button bindings and logs all motor/encoder data to NetworkTables.

**Architecture:** Each leaf subsystem gets a `testRun(double power)` method for direct motor control (bypassing PID/jam detection/feedforward) and a `publishTestTelemetry()` method gated behind a `m_testMode` flag in `periodic()`. RobotContainer uses a separate `EventLoop` for test-mode trigger bindings so they don't conflict with teleop bindings. Turret (which has 3 motor groups in one subsystem) uses a polling-based default command instead of individual trigger bindings to allow simultaneous motor control. Robot.java lifecycle hooks swap between modes.

**Tech Stack:** WPILib CommandScheduler EventLoop, NetworkTables DoublePublisher, REV SparkFlex API

### Task 7: Wire up test mode in RobotContainer

**Files:**
- Modify: `src/main/java/frc/robot/RobotContainer.java`

This is the most complex task. Key design decisions:
- A separate `EventLoop` (`m_testLoop`) holds test-mode trigger bindings so they don't fire during teleop.
- `CommandScheduler.setActiveButtonLoop()` swaps between the default loop (teleop) and `m_testLoop` (test).
- Turret has 3 motor groups in one subsystem, so it uses a **polling default command** (reads button state from the HID directly) instead of trigger bindings. This allows controlling multiple turret motors simultaneously.
- All other subsystems use standard `whileTrue` trigger bindings on `m_testLoop`.

```java
  // ─── Test Mode Bindings ─────────────────────────────────────────────────────

  /**
   * Registers test-mode button bindings on a separate EventLoop.
   * These bindings only fire when the test loop is the active button loop.
   *
   * <p>All non-drivetrain motors run at 0.1 power while held, stop on release.
   * Turret motors are polled from a default command (see configureTestMode).
   */
  private void configureTestBindings() {
    // Left trigger (held) → Gather forward (+0.1)
    m_driverController.axisGreaterThan(XboxController.Axis.kLeftTrigger.value, 0.08, m_testLoop)
        .whileTrue(Commands.run(() -> m_gather.testRun(0.1), m_gather));

    // Left bumper (held) → Gather reverse (-0.1)
    m_driverController.button(XboxController.Button.kLeftBumper.value, m_testLoop)
        .whileTrue(Commands.run(() -> m_gather.testRun(-0.1), m_gather));

    // Right trigger (held) → Feeder forward (+0.1)
    m_driverController.axisGreaterThan(XboxController.Axis.kRightTrigger.value, 0.15, m_testLoop)
        .whileTrue(Commands.run(() -> m_feeder.testRun(0.1), m_feeder));

    // D-pad Down (held) → Feeder reverse (-0.1)
    m_driverController.pov(180, m_testLoop)
        .whileTrue(Commands.run(() -> m_feeder.testRun(-0.1), m_feeder));

    // Right bumper (held) → Spindex (+0.1)
    m_driverController.button(XboxController.Button.kRightBumper.value, m_testLoop)
        .whileTrue(Commands.run(() -> m_spindex.testRun(0.1), m_spindex));

    // Y (held) → Hopper forward (+0.1)
    m_driverController.button(XboxController.Button.kY.value, m_testLoop)
        .whileTrue(Commands.run(() -> m_hopper.testRun(0.1), m_hopper));

    // D-pad Up (held) → Hopper reverse (-0.1)
    m_driverController.pov(0, m_testLoop)
        .whileTrue(Commands.run(() -> m_hopper.testRun(-0.1), m_hopper));

    // Start (held) → Level1 up (+0.1)
    m_driverController.button(XboxController.Button.kStart.value, m_testLoop)
        .whileTrue(Commands.run(() -> m_level1.testRun(0.1), m_level1));

    // Back (held) → Level1 down (-0.1)
    m_driverController.button(XboxController.Button.kBack.value, m_testLoop)
        .whileTrue(Commands.run(() -> m_level1.testRun(-0.1), m_level1));

    // NOTE: Turret (A, B, X, D-pad Left, D-pad Right) is handled in the
    // turret test default command via HID polling — see configureTestMode().
  }
```

**Step 5: Add configureTestMode() and configureNormalMode() methods**

After `configureTestBindings()`, add:

```java
  // ─── Mode Switching ───────────────────────────────────────────────────────────

  /** Activates test mode: swaps button loop, sets test default commands, enables telemetry. */
  public void configureTestMode() {
    CommandScheduler.getInstance().cancelAll();
    CommandScheduler.getInstance().setActiveButtonLoop(m_testLoop);

    // Enable telemetry on all subsystems
    m_gather.setTestMode(true);
    m_hopper.setTestMode(true);
    m_spindex.setTestMode(true);
    m_feeder.setTestMode(true);
    m_turret.setTestMode(true);
    m_level1.setTestMode(true);

    // Drive: same as teleop
    m_drive.setDefaultCommand(
        m_drive.applyRequest(() -> buildFieldCentricRequest()));

    // Simple subsystems: idle at 0 power (trigger bindings override when held)
    m_gather.setDefaultCommand(Commands.run(() -> m_gather.testRun(0), m_gather));
    m_hopper.setDefaultCommand(Commands.run(() -> m_hopper.testRun(0), m_hopper));
    m_spindex.setDefaultCommand(Commands.run(() -> m_spindex.testRun(0), m_spindex));
    m_feeder.setDefaultCommand(Commands.run(() -> m_feeder.testRun(0), m_feeder));
    m_level1.setDefaultCommand(Commands.run(() -> m_level1.testRun(0), m_level1));

    // Turret: polling default command (3 motor groups in one subsystem)
    m_turret.setDefaultCommand(Commands.run(() -> {
      var hid = m_driverController.getHID();

      double launchPower = hid.getAButton() ? 0.1 : 0;
      double hoodPower   = hid.getBButton() ? 0.1 : (hid.getPOV() == 90 ? -0.1 : 0);
      double rotatePower = hid.getXButton() ? 0.1 : (hid.getPOV() == 270 ? -0.1 : 0);

      m_turret.testRunLaunch(launchPower);
      m_turret.testRunHood(hoodPower);
      m_turret.testRunRotate(rotatePower);
    }, m_turret));
  }

  /** Restores normal teleop mode: swaps button loop back, restores normal default commands. */
  public void configureNormalMode() {
    CommandScheduler.getInstance().cancelAll();
    CommandScheduler.getInstance().setActiveButtonLoop(
        CommandScheduler.getInstance().getDefaultButtonLoop());

    // Disable test telemetry
    m_gather.setTestMode(false);
    m_hopper.setTestMode(false);
    m_spindex.setTestMode(false);
    m_feeder.setTestMode(false);
    m_turret.setTestMode(false);
    m_level1.setTestMode(false);

    configureDefaultCommands();
  }
```

Run: `./gradlew build`
